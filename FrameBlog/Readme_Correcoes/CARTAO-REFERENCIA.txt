📋 BUGS CORRIGIDOS
═══════════════════════════════════════════════════════════════════

1. User.getAuthorities() - linha 92
   ANTES: return List.of(new SimpleGrantedAuthority(role.name()));
   DEPOIS: return List.of(new SimpleGrantedAuthority("ROLE_" + role.name()));
   MOTIVO: Spring Security espera "ROLE_" no prefixo

2. SecurityFilter.extractToken() - linhas 43-52
   ANTES: authHeader.split(" ")[0].equals("Bearer ")
   DEPOIS: authHeader.startsWith("Bearer ")
   MOTIVO: Split é ineficiente e pode falhar

3. UserServiceImpl.save() - linhas 24, 30
   ANTES: user.getName() e user.getPassword()
   DEPOIS: user.getUsername() e passwordHash
   MOTIVO: Senha nunca deve ser texto plano

4. UserServiceImpl.update() - linha 58
   ANTES: userUpdate.setPassword(user.getPassword());
   DEPOIS: userUpdate.setPassword(passwordHash);
   MOTIVO: Senha nunca deve ser texto plano

5. AuthenticationServiceImpl.loadUserByUsername() - linhas 27-32
   ANTES: return userRepository.findByUsername(login);
   DEPOIS: if (user == null) throw exception;
   MOTIVO: Deve lançar exceção, não retornar null

6. SpringSecurityAuthentication - removido DaoAuthenticationProvider
   MOTIVO: Spring 6 auto-configura quando UserDetailsService existe

   cd FrameBlog

   ./mvnw.cmd spring-boot:run
   (Espere: Started FrameBlogApplication)

3. CRIE USUÁRIO (Postman):
   POST http://localhost:5000/users/save
   {
     "name": "Test",
     "email": "test@test.com",
     "password": "teste123",
     "username": "test",
     "role": "USER"
   }
   Resposta esperada: ✅ 200 OK

   POST http://localhost:5000/login
   {
     "username": "test",
     "password": "teste123"
   }
   Resposta esperada: ✅ 200 OK com token JWT

5. ACESSE RECURSO (Postman):
   GET http://localhost:5000/users/getAll
   Authorization: Bearer seu_token_aqui
   Resposta esperada: ✅ 200 OK com lista
